# Privacy Policy & Terms

This is a personal, non-commercial project used only by its author.

- It accesses only the author's own Oura account, read-only, via OAuth2.
- Data is fetched on demand and stays on the author's machine; it is not sold, shared, or stored on any server operated by this project.
- OAuth tokens are stored locally and can be revoked at any time from the Oura account settings.
